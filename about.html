How I Work

Every project moves through the same three steps, with me at each one.

  1. Design

    We find the one thing your app has to do well, then design it until it feels obvious.

  2. Build

    I build it in real code early, so decisions get made on something you can use, not a slide.

  3. Ship

    I test it on real devices, ship it, and stay close while it’s new.
