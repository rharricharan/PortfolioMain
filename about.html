02How I work

  1. 01

    Design

    We find the one thing your app has to do well, then design it until it feels obvious.

  2. 02

    Build

    I build it in real code early, so decisions get made on something you can use, not a slide.

  3. 03

    Ship

    I test it on real devices, ship it, and stay close while it’s new.

03How I build with AI

I start with the system, design with intent, and let AI do the heavy lifting in code, with every decision still mine.

  1. 01

    The system comes first

    Type, colour, spacing and components are set before any screens. The AI works inside that system, so what it makes starts on brand instead of drifting.

  2. 02

    Design in Figma, build in code

    Figma is where I think and explore. Once a direction holds, it moves into real code early, so decisions get made on something people can use.

  3. 03

    AI as a fast pair of hands

    I direct, Claude Code builds. I bring the references, the taste and a lot of no; it writes, runs and screenshots the result so I can react in seconds.

  4. 04

    Every change checked

    Nothing ships on a guess. Each change is opened in a real browser, checked at phone and desktop sizes, and committed so there’s always a way back.

  5. 05

    Days, not months

    An idea goes from first sketch to a working, shipped product in days, and keeps improving after launch.

05How I built this site

I didn’t hand-write the code for this site. I wrote messages. Claude Code wrote the code, opened it in a browser, took screenshots and showed me; I brought the sketches, the references and the edits, often from my phone. Every animation, transition and case study was directed that way, then checked at every screen size before it shipped.
